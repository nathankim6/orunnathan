# 동형 모의고사 에이전트 (ZIP → HWPX 3부)

도구는 이 스킬 폴더의 `agent/` 에 있다(아래 `$SKILL` 은 이 SKILL.md 가 있는 폴더 — 저장소에서는
`.claude/skills/mock-exam-hwpx`, 개인 설치면 `~/.claude/skills/mock-exam-hwpx`). 파일을 읽고 분류하고 시험지를 조판하는 일은 스크립트가 하고,
**분석과 문항 집필은 Claude 가 한다.** 순서를 건너뛰지 않는다.

## 0. 준비

```bash
pip install -q -r $SKILL/agent/requirements.txt   # 처음 한 번. 안 되면 건너뛴다 — python-hwpx·olefile 은 agent/vendor 에 동봉되어 있다
```
claude.ai 채팅에서 돌 때: Playwright 가 없으니 `build` 는 PDF 미리보기를 건너뛰고 HWPX·HTML 만 낸다. 그래도 된다.

## 1. 자료 풀기·분류

```bash
python3 $SKILL/agent/agent.py ingest <자료.zip> <작업폴더>
```

`manifest.json` 에 파일마다 역할이 붙는다 — `exam`(기출) · `scope`(시험범위: 교과서 본문·대화문·어휘) ·
`worksheet`(학교 학습지·프린트) · `notes`(출제 성향 메모) · `unknown`. 이름으로 판단한 어림이므로
**목록을 보고 잘못 붙은 것은 머릿속에서 바로잡는다.** 텍스트가 나온 파일은 `text/NN.txt`,
스캔 PDF·사진은 `pages/NN/page-001.png …` 로 쪽 그림이 된다.

## 2. 읽기 — 빠짐없이, 그리고 세 갈래로 나눠서

읽는 자료는 역할이 다르다. 섞지 않는다.

| 역할 | 무엇 | 어디에 쓰나 |
|---|---|---|
| **기출**(exam) | 지난 시험지 | **형식과 유형의 기준**. 문항 수·배점·번호 흐름·유형·"어느 자료에서 뽑았나". 내용(지문·문장)은 지난 범위라 **쓰지 않는다** |
| **지침**(notes) | 학교별 txt | **명령**. 문항 수·서술형 유무·강조 유형·문법 확장·"학습지 비중"·"선생님 제작 문장"·시험범위 |
| **범위**(scope·worksheet) | 교과서 5·6과 자료(본문·대화문·어휘 xlsx/hwp), 학교 학습지·프린트(스캔), 통합본 | **출제 재료의 전부**. 지문·대화·문장·문법·어휘는 여기서만 |

1. `text/*.txt` 를 전부 읽는다. 기출 docx 의 `┌── … └──` 가 글상자(지문·대화 상자)다.
2. **스캔본(기출·학습지)은 쪽 그림을 Read 로 한 장도 빠짐없이 본다.** 이미 만들어 둔 `pages/` 그림을 다시 만들지 않는다.
3. **학습지 스캔은 텍스트로 옮겨 적는다** — `<작업폴더>/text/ws<파일번호>.txt` (예: `text/ws09.txt`). 문항에 그대로 쓸 문장이
   여기서 나오고, `audit` 도 이 파일을 본다. 규칙은 `scan-to-text` 스킬과 같다: 보이는 순서대로 빠짐없이, 쪽마다 `[p.N]`,
   문법 표·Practice 문장·어휘 표·영영풀이·예문·학생 필기(정답 표시)까지. 요약·의역 금지, 못 읽는 글자는 `[?]`.
   (기출 스캔은 형식만 보면 되므로 옮겨 적지 않아도 된다.)
4. 지침 txt 는 문장 단위로 옮겨 적어 두고, 아래 분석표의 "지침 반영" 칸에 하나하나 대응시킨다.

## 3. 기출을 한 문항씩 분석한다 — `analysis.md` 의 표 ①

```bash
python3 $SKILL/agent/agent.py profile <작업폴더>      # 뼈대 표(번호·배점·유형 어림) — 출발점
```

이 뼈대를 기출 원문과 대조해 **문항마다 한 줄**로 채운다. 이것이 표 ① "기출 문항 분석표" 다.

| 번호 | 배점 | 유형 | 묶음 | 기출이 뽑은 자료 | 무엇을 묻나(포인트) |
|---|---|---|---|---|---|
| 8 | 3 | 문장 빈칸에 못 들어가는 단어 | 단독 | **학교 학습지** 어휘 워크북 문장 그대로 | 단원 어휘 4개 |
| 15~18 | 3·3·4·4 | 문장 삽입·지칭·질문·어법 | 본문 세트 | **교과서 본문** 통째 | 지시어, 비교급 오류 |

"기출이 뽑은 자료" 는 반드시 다음 중 하나로 적는다 — 교과서 본문 / 교과서 대화문 / 교과서 기타 지문 / 어휘 영영풀이 / 학교 학습지(어느 쪽) / 선생님 제작 문장 / 그림·표.
판단 근거는 문장을 대조해서 얻는다(기출 문장이 학습지 문장과 같으면 학습지).

## 4. 이번 범위를 분석하고, 문항마다 출처를 예측한다 — 표 ②·③

먼저 범위 자료의 **목록**을 만든다(표 ②) — 본문 대목(문단 단위로 번호), 대화문(Watch&Talk A-1 … Review), 기타 지문, 어휘(영영풀이·다의어·숙어), 학습지 쪽마다 무엇이 있는지(문법 항목·Practice 문장·어휘 표), 통합본 문법 항목. **이 목록에 없는 것은 시험에 넣을 수 없다.**

그다음 표 ③ "출제 예측표" — 기출 문항 하나하나에 대해 이번 범위에서 무엇으로 바꿔 낼지 정한다.

| 번호 | 기출 유형·자료 | 이번 범위에서 뽑을 자료(구체 대목) | 1회 | 2회 | 3회 |
|---|---|---|---|---|---|
| 8 | 어휘 빈칸 · 학습지 | 학습지 L6 Vocabulary Advanced B 문장 4개 | reduce/sew/delivery/label | … | … |
| 15~18 | 본문 세트 · 교과서 본문 | L5 본문 3대목 중 하나 | Shoreditch·STIK | Banksy | Wilson |

지킬 것:
- **문법·어법 문항의 포인트는 이번 범위의 문법(학습지 Grammar 쪽·통합본 GRAMMAR)에서만.** 기출에 나온 문법이라도 이번 범위에 없으면 내지 않는다. 지침이 "누적·연계·확장" 을 말하면 그 범위(예: 1학기 문법, 사역동사)까지만 더한다.
- 기출이 학습지에서 뽑은 자리는 이번 학습지에서, 본문에서 뽑은 자리는 이번 본문에서 — **자료의 갈래를 바꾸지 않는다.** 지침의 "학습지 비중 높음"·"선생님 제작 문장"·"본문·대화문 변형 없음" 이 이 판단을 바꾼다.
- **문항에 들어가는 영어 문장은 전부 범위 자료(교과서 xlsx·학습지 옮겨 적은 것·통합본)의 문장 그대로다.** 지문·대화만이 아니라
  **선지·<보기>·조건·서술형 재료 문장까지.** 허용되는 손질은 셋뿐 — ① 어법 오류 심기(원문 한 단어·한 구만 바꿈, explain 에 원문 표기),
  ② 빈칸·밑줄·기호 넣기, ③ 일치/불일치·요약·순서 선지처럼 원문을 한 단어(숫자·이름·부정어)만 바꿔 틀리게 만들기.
  새 문장을 지어 넣지 않는다 — 지침이 "선생님 제작 문장" 이라 한 학교도 **학습지·교과서 문장에 한 군데 손질**이 먼저고,
  그래도 안 되는 자리만 짓되 analysis 비고에 문항 번호와 이유를 적는다. 사례·적용형 선지("S1: …")도 범위 문장을 쓴다.
- 3부는 같은 자리에 같은 유형·같은 자료 갈래, 다른 대목. 대목이 모자라면 같은 대목에 다른 유형.
- 그림·표가 필요한 유형은 글로 같은 것을 묻는 형태로 바꾸고 표 ③ 비고에 적는다.

표 ①·②·③ 과 지침 반영 목록을 `analysis.md` 로 쓴다. 견본: `$SKILL/agent/samples/*/analysis.md`.

## 4-1. 문항 집필 — 3부, 각각 JSON 한 개

형식은 `$SKILL/agent/README.md` 의 spec 설명을 따른다. 표 ③ 의 줄 하나가 문항 하나다 — 표에 없는 문항을 만들지 않는다.
`answer` · `explain` · `source`(표 ③ 의 자료 대목을 그대로) 를 문항마다 채우고, 정답이 하나뿐인지 다시 읽는다.

```bash
python3 $SKILL/agent/agent.py check set1.json set2.json set3.json          # 배점 합·선지 수·정답
python3 $SKILL/agent/agent.py audit <작업폴더> set1.json set2.json set3.json  # 지문·대화 문장이 범위 자료에 있는가
```

`audit` 는 문항의 **모든 영어 문장**(상자·선지·보기·조건)을 범위 텍스트(교과서 xlsx/hwp·통합본·`text/ws*.txt`)와 대조해
원문 그대로 / 변형(원문과 단어 60 % 이상 겹침) / **창작**(짝 없음) 으로 나눈다. **창작이 0 이 될 때까지 고친 뒤에야 build 한다.**
변형은 어법 오류 심기·한 단어 바꾼 오답 선지만 남긴다. 어쩔 수 없이 남는 창작은 analysis 비고에 번호·이유를 적는다.

## 4-2. 풀어 보기(검토)와 해설 쓰기

집필이 끝나면 **정답을 가리고 전 문항을 처음부터 풀어 본다** (spec 의 `answer`·`explain` 을 보지 않고 stem·box·choices 만으로).
푼 답과 `answer` 가 다르거나, 답이 둘 이상 되거나, 답이 없거나, 오타·모순·범위 밖 정보가 있으면 그 문항을 고친다
(고친 것은 analysis 비고에 번호·이유). 그다음 문항마다 `explain` 을 해설지 수준으로 쓴다 — 정답 근거(지문 문장 인용),
문법 규칙, **오답 선지가 왜 틀리는지**(`wrong` 배열에 선지별로), 서술형은 채점 기준. `build` 가 이것으로 **별도 해설지 HWPX** 를 만든다.

## 5. 조판·검증·전달

```bash
python3 $SKILL/agent/agent.py build set1.json set2.json set3.json -o <출력폴더>
```

`OO중학교_O학년_O학기_OO고사_동형모의고사_N회.hwpx`(시험지, 정답 없음)와 `…_N회_해설.hwpx`(정답 한눈에 표 + 문항별 해설)가 나온다. 판형은 **실제 학교 시험지 서식**
`$SKILL/agent/assets/exam-template.hwpx` 를 열어 채우는 것이라 손대지 않는다 — 머리말(`2026학년도 2학기 중간고사`) ·
정보표(학년·회차·과목·문항수·쪽수·출판사·학교·회차) · 안내문 · 2단 · 꼬리말(`1학년 영어 과목 · 쪽/전체 · 옳은영어 ORUN ENGLISH`) ·
글꼴(맑은 고딕 10pt) · 문단 모양이 모두 서식의 것이다. spec 의 `year` · `publisher` 를 채우면 머리말·정보표에 들어간다.

HWPX 는 스키마 검증을 지나야 저장된다. **이 환경에는 한글이 없다.** `.pdf` 미리보기는 구성 확인용일 뿐
줄 바꿈·쪽 수는 한글과 다르므로, 파일을 보내고 사용자가 한글에서 본 캡처로 마무리한다.

끝나면 **HWPX 3개 + analysis.md** 를 사용자에게 준다 — Claude Code 는 `SendUserFile`, claude.ai 채팅은 `/mnt/user-data/outputs/` 에 복사(PDF 는 요청할 때만).
저장소에 남길 때는 `$SKILL/agent/samples/<학교-학년-학기-고사>/` 에 spec·analysis·hwpx 를 둔다.

## 판형에서 이미 정해진 것 (다시 묻지 않는다)

사용자가 한글 화면을 보며 잡아 준 규칙이다. render.py 에 들어 있으니 spec 만 쓰면 된다.

- 지문·대화 상자: 실선 0.12 mm, 안쪽 여백 좌우 1.5 / 상하 0.8 mm, 맑은 고딕, 양쪽 정렬. 상자 뒤에 빈 줄 한 줄, 그다음 선지·발문.
- 긴 지문 상자는 쪽·단 경계에서 나뉘어 이어진다(표 "쪽 경계에서 나눔"). 지시문·발문은 다음 문단과 붙어 다닌다.
- 선지는 들여쓰기 없이 발문과 같은 왼쪽에서 시작. ⓐⓑⓒ 조합 선지는 **표가 아니라 탭 글줄**(한글이 표 폭·테두리를 제멋대로 그린다).
  탭 자리는 칸마다 가장 긴 글 너비로 계산한다.
- 로고 없음(`USE_LOGO=False`), 꼬리말 저작권 문구 없음.
- 정답·해설은 마지막 쪽 1단 표 한 장. 행은 최소 높이만 주고 한글이 늘리게 둔다 — 높이를 크게 주면 표가 통째로 다음 쪽으로 밀린다.

## 자주 틀리는 것

- 기출 docx 의 지문이 안 보인다 → 글상자에 들어 있다. `ingest` 가 `┌──` 로 꺼내 준다. 빠져 있으면
  `mc:AlternateContent` 안의 VML(Fallback) 이 아닌 Choice 쪽만 읽고 있는지 본다.
- `.hwp`(5.0 바이너리) 는 본문 텍스트만 나온다. 표 안 문장은 순서가 섞일 수 있어 같은 내용의 xlsx 가 있으면 그쪽을 믿는다.
- 스캔 PDF 는 텍스트가 0 이다. `pages/` 그림을 읽는 것 말고 길이 없다. 글자가 작으면 `ingest.py` 의 dpi 를 올린다.
- LibreOffice 는 이 환경에서 파일을 못 연다. 미리보기는 Playwright(Chromium)로 HTML→PDF 로 만든다.
- 한글에서 표가 XML 값과 다르게(좁게·테두리 있게) 보이면 표를 버리고 탭 글줄로 간다. 셀 최소 높이는 한글이 늘리므로 합계를 쪽 안에 두어야 한다.
- 다른 학교 서식을 쓰려면 그 학교 HWPX 를 `assets/exam-template.hwpx` 에 두고 `render.py` 의 `T` 표(문단·글자·테두리 id)를 그 파일 값으로 맞춘다.

## 4. 비고

- 기출 21번 포스터(표)는 글상자 안 메모 문장 ①~⑤ 로 바꿔 같은 것을 물었다. 메모 문장은 대화문·통합본 요약문 그대로이고 한 줄만 한 단어(요일·less/more·actor/singer)를 바꿨다.
- 1번 연결어 빈칸은 원문의 `, so` 를 두 문장으로 나눠 `__(A)__,` 로 만들었다(1·3회). 2회는 원문에 연결어가 없는 자리(`He began to take pictures.`) 앞에 넣어 Then/Soon/After that/Right away vs However 로 물었다 — 확신 낮음.
- 4번(대답을 찾을 수 없는 질문)은 통합본 L6 본문 문제의 질문(`When did Dr. Schofield first come to Korea?` 등)을 그대로 쓰고, 2회만 본문·T/F 문장을 의문문으로 바꿨다(한 단어 이내 변형).
- 5번 순서 배열 보기, 16번 요약문, 17번 일치 선지, 18번 학생 발화는 교과서 본문 문장 또는 통합본 본문 T/F 문장 그대로이고 오답은 한 단어(숫자·이름·부정어·장소)만 바꿨다.
- 12번(사례 적용)은 범위 안에 "메시지 사례" 문장이 없어 형식을 바꿨다 — 1회는 Culture Project·대화문의 "남을 도운 사람" 문장 4개 + 학습지 문장 1개, 2회는 Banksy 그림에 대한 통합본 T/F 문장(학생 발화), 3회는 껌 그림 메시지 문구(짧은 인용).
- 3회 서답형3 의 A 대사는 학습지 p.4 Practice B-4 문장(`Did this place use to be a bookstore a long time ago?`)이고, 답 문장은 Practice B-6 그대로.
- 3회 24번 ①(who 를 목적격으로 쓴 문장)은 구어에서 허용되나 학습지 p.5 표(사람 → whom, 전치사 뒤 whom)에 따라 오답 처리 — 해설에 적어 두었다. 확신 낮음.
- 통합본 문법 예문의 우리말은 통합본 표기를 그대로 썼다.
- PDF 미리보기는 Playwright 로 만든 구성 확인용이며 줄 바꿈·쪽 수는 한글과 다르다.

## 1. 기출 형식 (1학기 중간고사 25문항을 그대로 따른다)

- 선택형 25 = **3점×6 + 4점×13 + 5점×6 = 100점. 서술형 없음.** (기말은 26문항, 듣기 1~6 포함 — 이번엔 중간 형식)
- 배점 자리: 3점 = 1·4·7·8·10·12, 5점 = 9·16·18·20·24·25, 나머지 4점.
- 번호 흐름: 어휘·표현(1~4) → 대화 세트 [5-6]·[7-8]·9·[10-11]·12 → 어법(13) → 짧은 글(14·15·16) → 어법(17·18·19) → 글(20) →
  본문 세트 [21-22]·[23-24] → 학생 발언 평가(25).
- 상자: 대화·지문은 실선 상자, 선지는 짧으면 한 줄(inline). 지시문 `[5-6] 다음 대화문을 읽고, 물음에 답하시오.`
- 판형: 학교 서식 HWPX(정보표·안내문·2단). `2026학년도 2학기 중간고사 · 영어 · 2학년 · 코드 01~03`.

## 4. 메모 반영 사항

- 대화문: 빈칸(5·7·12) · 내용 일치(8) · 순서 배열(9) — 메모의 세 유형 모두 매 회 포함.
- 본문: 함축 의미(11·21) · 글의 목적(14) · 빈칸 어휘(15·22·23) · 흐름상 어색한 문장(16) · 내용 일치(24).
- 어법: 본문 어법(13·25) · 옳지 않은 것(18) · 배열 영작 네 번째 단어(17) · 학생 발언 평가(25).
  핵심 문법 확장 — 목적격 관계대명사 whom(1회 18⑤), 명사절 that vs 관계대명사 that vs so~that의 that(3회 25),
  사역동사 make(2회 18④·3회 19), 준사역·want/tell/ask + to부정사(1회 19·3회 19).
- 어휘: 맥락상 빈칸(2·4·15·22·23) · 문맥 부적절(1).
- "선생님 자체 제작 문장" — 1·3·13·18·19 의 예문은 학습지 문장을 우선 쓰고 일부는 교과서 문법으로 새로 만들었다.
- 본문·대화문은 xlsx 문장 그대로(변형 없음). 16번은 어색한 문장 하나만 끼워 넣었고, 3회 [23-24]는 도입 4문장 뒤에
  "On the wall, ~" 단락을 이어 붙였다(문장 자체는 그대로).
- 그림·표 유형 대체: 기출 9번(설문 조사 표)은 표 없이 대화 순서 배열로, 기출 19번 '정답 2개'는 조합 선지로 바꾸어
  단일 정답(①~⑤)이 되게 했다. 듣기 문항 없음(중간 형식).

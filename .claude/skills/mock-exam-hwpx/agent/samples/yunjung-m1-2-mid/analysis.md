## 3. 출제자 성향 (메모 + 기출 대조)

- 메모의 대표 유형 다섯 가지가 기출에 그대로 있다 — 다의어(7) · 제목(12) · 어법 옳은 문장(13) · 비교급 3자 관계(18) · 어법 조합(19). 3부 모두 같은 자리에 두었다.
- 흐름도 메모와 같다 — 대화(1~5) → 독해 세트(6~9) → 어법 단문(10) → 이야기 세트(11~17) → 추론 단문(18~20) → 서술형.
- **문법은 4단원(과거시제·동명사 vs to부정사)과 5단원(비교급·최상급)** 두 축이다. 10·13·19·서6 은 4단원, 14·18·서3·서7 은 5단원. 문법 예문은 모두 학습지 Let's Practice · 연습 문장에서 가져왔다.
- **학습지 비중이 높다.** 기출 13·19 의 문장(Eating vegetables is healthy / Watching action movies are fun / Jack is really good at play tennis / decided to move to Busan …)이 학습지 4-7·4-8 그대로였다. 서5 의 Would you like some ice cream 도 학습지 4-10 06 번 그대로.
- **시험 범위 반영** — 6단원 본문(Joys of Working in Nature)은 쓰지 않았다. 6단원은 대화문·Enjoy the Clip·Review 대화만 썼다. 4단원은 문법과 추가 자료(More Reading 4-9)만 썼고, 기출의 4단원 여행 일기 본문(Damyang·Tongyeong·Jeju)은 올해 범위 밖이라 쓰지 않았다.
- 본문(Growing Season)은 세 대목(1~7 · 8~21 · 21~28)으로 갈라 부마다 14 · 15~17 · 20 에 돌려 썼다.

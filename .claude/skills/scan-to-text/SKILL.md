# 스캔본 → 텍스트

동형 모의고사 생성기(아티팩트)는 뷰어가 이미지를 보내지 못하면 스캔본을 읽을 수 없다.
이 스킬은 그 빈자리를 메운다: Claude Code 가 구독으로 쪽 그림을 직접 보고 글자를 옮겨 적어
`.txt` 로 준다. 사용자는 그 텍스트를 아티팩트의 붙여넣기 칸에 넣으면 된다.

## 절차

1. **입력 찾기.** 인자로 받은 경로, 대화에 첨부된 파일, 또는 `scan-in/` 폴더의 PDF·이미지.
   여러 개면 각각 처리한다.
2. **쪽 그림 만들기.**
   ```bash
   python3 .claude/skills/scan-to-text/render_pages.py "<입력파일>" scan-out/<이름>/pages
   ```
   쪽별 `page-001.png …` 경로가 출력된다. (기본 150dpi, 최대 40쪽. 글자가 작으면 `--dpi 200`.)
3. **읽기.** 쪽 그림을 순서대로 Read 도구로 열어 본다. 한 번에 한 쪽씩, 빠뜨리지 않는다.
4. **옮겨 적기.** 아래 규칙대로 `scan-out/<이름>.txt` 에 쓴다.
5. **전달.** SendUserFile 로 `.txt` 를 보내고, 붙여넣을 위치를 한 줄로 안내한다:
   시험지면 "시험지 화면 → 본문을 직접 붙여넣을게요", 범위 자료면 "시험범위 화면 → 본문 붙여넣기".

## 옮겨 적기 규칙 (생성기의 OCR 규칙과 동일)

1. 보이는 내용을 빠짐없이, 보이는 순서대로 그대로 옮겨 적는다. 요약·의역 금지.
2. 각 쪽의 시작에 `[p.쪽번호]` 를 한 줄로 넣는다.
3. 문항 번호, 배점 표기(`[3점]` 등), 선택지 기호(①②③④⑤)를 원문 그대로 유지한다.
4. 영어 지문은 철자·구두점을 그대로 옮긴다. 고쳐 쓰지 않는다.
5. 밑줄·굵게 표시는 그 자리에 `<u>…</u>` 로 표시한다. 빈칸은 `________` 로 둔다.
6. 표는 각 행을 한 줄로, 칸은 `|` 로 나눈다.
7. 읽을 수 없는 글자는 `[?]` 로 둔다. 추측해서 지어내지 않는다.
8. 2단 편집이면 왼쪽 단을 끝까지 적은 뒤 오른쪽 단을 적는다.
9. 파일에는 옮겨 적은 내용만 넣는다. 설명·인사말 없이.

## 참고

- 스캔 상태가 나쁜 쪽은 `--dpi 200` 으로 다시 만들어 읽는다.
- 40쪽을 넘는 자료는 `--max` 를 올리거나 파일을 나눠서 처리한다.
- `scan-in/`, `scan-out/` 은 작업 폴더다. 사용자가 원하면 결과를 커밋해도 되지만 기본은 커밋하지 않는다.

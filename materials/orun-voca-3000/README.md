# 옳은 VOCA 3000 · 정시반 필수 영단어

옳은영어 정시반 학생용 단어장과 별책 시험지입니다. 원본 엑셀(3,000단어)을 **알파벳순이 아니라
난이도순**으로 다시 배열하고, **하루 100단어 × 30 DAY**로 나눠 A4 교재 두 권으로 만들었습니다.

| [`옳은영어_정시반_VOCA_3000.docx`](./옳은영어_정시반_VOCA_3000.docx) · [`.pdf`](./옳은영어_정시반_VOCA_3000.pdf) | 57면 | **단어장** — DAY 30면(한 면 100단어) + 다의어 정리 + 색인 |
| [`옳은영어_정시반_VOCA_3000_단어시험지.docx`](./옳은영어_정시반_VOCA_3000_단어시험지.docx) · [`.pdf`](./옳은영어_정시반_VOCA_3000_단어시험지.pdf) | 59면 | **별책 시험지** — DAY 시험 30회 + 다의어 시험 8회 + 정답 |

> Word 원본은 **Noto Sans KR**로 짜여 있습니다. 이 글꼴이 없는 컴퓨터에서 열면 글자가 다르게

> 내려받아 설치한 뒤 여세요. 인쇄만 할 거라면 PDF를 쓰면 됩니다.

## 난이도 재배열

원본은 `a, abandon, able …` 순서라 다섯 번째에 벌써 `abort(유산하다, 전문)`가 나왔습니다.
이 책은 같은 3,000단어를 원본의 등급 열대로 세 파트로 나누고, **파트 안에서만** 알파벳순으로
정렬했습니다. 단어는 하나도 빠지거나 겹치지 않습니다.

| PART | 난이도 | 원본 등급 | 수록 | 학습 범위 | 통번호 |
|---|---|---|---|---|---|
| I · FOUNDATION | 초·중등 기초 | `초등` | 800단어 | DAY 01–08 | #0001–0800 |
| II · CORE | 중·고 핵심 | `중고` | 1,800단어 | DAY 09–26 | #0801–2600 |
| III · ADVANCED | 전문 심화 | `전문` | 400단어 | DAY 27–30 | #2601–3000 |

800 / 1,800 / 400이 모두 100의 배수라 파트 경계가 DAY 경계와 정확히 맞아떨어집니다.

## 단어장 (57면)

- **표지** 1면
- **이 책의 구성과 활용법 · 학습 플래너** 2면 — DAY 30칸에 날짜·3회독·시험 점수 기록
- **PART 도비라** 3면
- **DAY 01–30** 30면 — **한 면에 100단어**(2단 × 50행), 단어마다 체크 칸 □
- **부록 · 다의어 정리** 5면 — 145단어의 뜻 516개
- **알파벳 색인** 16면 — 3,000단어를 DAY 번호와 함께 (난이도순 배열이라 색인이 필요합니다)

## 별책 시험지 (59면)

시험은 **영어 단어를 보고 우리말 뜻을 쓰는 형식만** 씁니다. 객관식도, 한→영도 없습니다.

- **표지 · 사용 안내 · 성적 기록표** 3면
- **DAY 01–30 단어시험** 30면 — 한 면에 **100문항**(그 DAY 100단어 전부), 4단 × 25행
  - 단어장에 실린 순서 그대로가 아니라 **섞어서** 냅니다(3,000문항 중 2,967문항이 자리를 바꿈).
    순서로 외운 학생과 뜻으로 외운 학생이 여기서 갈립니다.
- **다의어 시험 01–08** 9면(도비라 포함) — 회당 20문항, `( 4개 )`처럼 답 개수를 알려 주고
  그 수만큼 쓰게 합니다
- **정답** 17면 — DAY 시험 30회분 + 다의어 시험 8회분

## 다의어 파트

원본 엑셀은 단어마다 뜻을 **하나만** 달아 두었습니다. `run = 달리다`, `light = 빛`,
`right = 올바른` 식이라, 정작 지문에서 발목을 잡는 나머지 뜻이 없습니다.

그래서 수능·모의고사 빈출 다의어 **145단어**를 골라 뜻을 모두 채워 넣었습니다
(`build/polysemy.py`). 단어장 뒤 「부록 · 다의어 정리」에서 익히고, 시험지의 「다의어 시험」에서
확인하는 구성입니다.

```
run    ① 달리다  ② 운영하다, 경영하다  ③ (액체가) 흐르다  ④ (기계가) 작동하다
charge ① 요금  ② 청구하다  ③ 충전하다  ④ 책임, 담당  ⑤ 고발하다
```

145단어 모두 원본 3,000단어 안에 있는 것으로만 골랐습니다(`prep.py`가 검사합니다). 다만
`course · issue · party · set · second · spring`은 대표적인 다의어인데도 **원본 3,000단어에
없어서** 뺐습니다. 넣으려면 `polysemy.py`에 되살리고 `prep.py`의 “3,000단어에 없는 다의어”
검사를 풀면 됩니다.

## 디자인

옳은영어 v2 에디토리얼 규칙을 따랐습니다.

- 옐로우(`FFD400`)는 작은 사각 점 `■`, 잉크 블록 위 숫자, 다의어 `①` 표시에만 씁니다.
  옐로우 면·색 띠는 없습니다.
- 표는 세로선 없이 가로 헤어라인(`E4E2DD` 0.5pt)만. 머리글은 배경 없이 회색 자간 글자에
  잉크 1.5pt 밑줄.
- 팔레트 — 잉크 `1C1C1C`, 본문 `3A3A3A`, 회색 `8A8A8A`, 종이 `F7F6F2`, 블루 `1A7FBF`,
  연한 블루 `EAF4FA`.
- A4, 여백 2cm, 본문 폭 9638 DXA, 글꼴 Noto Sans KR.
- 모든 면에 레터헤드(로고 + `ORUN ENGLISH` + 파트명)와 바닥글(페이지 번호).

한 면에 100단어를 넣느라 DAY 면의 활자는 작습니다(표제어 7.5pt, 뜻 7pt). 뜻이 몇 줄로 접히는지
미리 계산해 **행 높이를 면마다 다르게** 잡기 때문에, 뜻이 긴 DAY도 짧은 DAY도 한 면을 고르게
채우고 넘치지 않습니다. 시험지의 정답면도 같은 방식으로 블록 높이를 재서 면에 채워 넣습니다.

## 다시 만들기

문구를 고치거나 원본 엑셀이 바뀌면 이렇게 다시 뽑습니다.

```sh
cd build
pip install xlrd            # 엑셀 읽기 (처음 한 번)
npm install                 # docx 라이브러리 (처음 한 번)
python3 prep.py             # 엑셀 -> book.json (난이도 재배열 + 시험 문항 + 검증)
node gen.js       "../옳은영어_정시반_VOCA_3000.docx"
node gen_test.js  "../옳은영어_정시반_VOCA_3000_단어시험지.docx"
```

`prep.py`는 만들면서 스스로 검사합니다 — 단어 수, 빠지거나 겹친 단어, 통번호 연속성, 파트별
등급, 파트 안 알파벳순, DAY 분량, 색인의 DAY 번호, 시험지가 그 DAY 단어를 하나도 빠뜨리지 않고
딱 한 번씩 내는지, 다의어가 모두 3,000단어 안에 있고 뜻이 둘 이상인지. 하나라도 어긋나면
파일을 쓰지 않고 멈춥니다.

시험 문항 순서는 `SEED`로 고정해 두었으므로, 다시 돌려도 **같은 시험지와 같은 정답**이 나옵니다.

PDF는 Word에서 «다른 이름으로 저장 → PDF»로 만들거나, LibreOffice가 깔린 곳에서:

```sh
soffice --headless --convert-to pdf "옳은영어_정시반_VOCA_3000.docx"
```

# 옳은 VOCA 3000 · 정시반 필수 영단어

옳은영어 정시반 학생용 단어장입니다. 원본 엑셀(3,000단어)을 **알파벳순이 아니라 난이도순**으로
다시 배열해 A4 116면 교재 한 권으로 만들었습니다.

| 파일 | 내용 |
|---|---|
| [`옳은영어_정시반_VOCA_3000.docx`](./옳은영어_정시반_VOCA_3000.docx) | Word 원본. 문구·디자인을 고칠 때 이 파일을 엽니다 |
| [`옳은영어_정시반_VOCA_3000.pdf`](./옳은영어_정시반_VOCA_3000.pdf) | 인쇄·배포용. docx와 내용이 같습니다 |
| `source/단어장_원본_3000.xls` | 학원에서 준 원본 엑셀 (건드리지 않습니다) |
| `build/` | 엑셀에서 교재를 다시 뽑는 스크립트 |

> Word 원본은 **Noto Sans KR**로 짜여 있습니다. 이 글꼴이 없는 컴퓨터에서 열면 글자가 다르게
> 보일 수 있으니, [Google Fonts](https://fonts.google.com/noto/specimen/Noto+Sans+KR)에서
> 내려받아 설치한 뒤 여세요. 인쇄만 할 거라면 PDF를 쓰면 됩니다.

## 난이도 재배열

원본은 `a, abandon, able …` 순서라 첫 장부터 `abort(유산하다, 전문)` 같은 어려운 단어가 섞여
나왔습니다. 이 책은 같은 3,000단어를 원본의 등급 열대로 세 파트로 나누고, **파트 안에서만**
알파벳순으로 정렬했습니다. 단어는 하나도 빠지거나 겹치지 않습니다.

| PART | 난이도 | 원본 등급 | 수록 | 학습 범위 | 통번호 |
|---|---|---|---|---|---|
| I · FOUNDATION | 초·중등 기초 | `초등` | 800단어 | DAY 01–20 | #0001–0800 |
| II · CORE | 중·고 핵심 | `중고` | 1,800단어 | DAY 21–65 | #0801–2600 |
| III · ADVANCED | 전문 심화 | `전문` | 400단어 | DAY 66–75 | #2601–3000 |

## 책의 구성 (116면)

- **표지** 1면
- **이 책의 구성과 활용법 · 학습 플래너** 2면 — DAY 75칸에 날짜와 3회독 표시
- **PART 도비라** 3면
- **DAY 01–75** 75면 — 한 면에 40단어(2단), 단어마다 체크 칸, 아래에 「오늘 헷갈린 단어」 칸
- **REVIEW TEST 01–15** 15면 — DAY 5개마다 32문항 (A 영→한 16 + B 한→영 16)
- **REVIEW TEST 정답** 4면
- **알파벳 색인** 16면 — 3,000단어 전부를 DAY 번호와 함께 (난이도순 배열이라 색인이 필요합니다)

## 디자인

옳은영어 v2 에디토리얼 규칙을 따랐습니다.

- 옐로우(`FFD400`)는 작은 사각 점 `■`과 잉크 블록 위 숫자에만 씁니다. 옐로우 면·색 띠는 없습니다.
- 표는 세로선 없이 가로 헤어라인(`E4E2DD` 0.5pt)만 씁니다. 머리글은 배경 없이 회색 자간 글자에
  잉크 1.5pt 밑줄.
- 팔레트 — 잉크 `1C1C1C`, 본문 `3A3A3A`, 회색 `8A8A8A`, 종이 `F7F6F2`, 블루 `1A7FBF`,
  연한 블루 `EAF4FA`.
- A4, 여백 2cm, 본문 폭 9638 DXA, 글꼴 Noto Sans KR.
- 모든 면에 레터헤드(로고 + `ORUN ENGLISH` + 파트명)와 바닥글(페이지 번호)이 들어갑니다.

DAY·REVIEW 면은 **뜻이 몇 줄로 접히는지 미리 계산해 행 높이를 면마다 다르게** 잡습니다.
그래서 뜻이 긴 DAY 75도, 짧은 DAY 01도 한 면을 고르게 채우고 넘치지 않습니다.

## 다시 만들기

문구를 고치거나 원본 엑셀이 바뀌면 이렇게 다시 뽑습니다.

```sh
cd build
pip install xlrd            # 엑셀 읽기 (처음 한 번)
npm install                 # docx 라이브러리 (처음 한 번)
python3 prep.py             # 엑셀 -> book.json (난이도 재배열 + 검증)
node gen.js "../옳은영어_정시반_VOCA_3000.docx"
```

`prep.py`는 만들면서 스스로 검사합니다 — 단어 수, 빠지거나 겹친 단어, 통번호 연속성, 파트별
등급, 파트 안 알파벳순, 색인의 DAY 번호, REVIEW 문항이 해당 DAY 범위 안에서만 나왔는지.
하나라도 어긋나면 파일을 쓰지 않고 멈춥니다.

PDF는 Word에서 «다른 이름으로 저장 → PDF»로 만들거나, LibreOffice가 깔린 곳에서:

```sh
soffice --headless --convert-to pdf "옳은영어_정시반_VOCA_3000.docx"
```

### 손볼 만한 곳

| 무엇 | 어디 |
|---|---|
| 하루 분량, REVIEW 간격·문항 수 | `prep.py`의 `WORDS_PER_DAY` · `DAYS_PER_REVIEW` · `QUESTIONS_PER_REVIEW` |
| 파트 이름·설명글 | `prep.py`의 `PARTS` |
| 색·글꼴·본문 폭 | `gen.js` 위쪽 「팔레트 · 타이포」 |
| 활용법 안내 문구 | `gen.js`의 `frontMatter()` |

# 시험대비 리포트 자산 (ORUN HOMEWORK)

Lovable 프로젝트 **ORUN HOMEWORK** 의 `/exam-report` 리포트 카드가 쓰는 그림들이다.
Lovable 저장소에 직접 파일을 넣을 길이 없어 여기 두고, 앱은 빌드 때
`public/images/exam-report/` 로 내려받아 쓴다.

| 파일 | 쓰이는 곳 | 크기 |
|---|---|---|
| `header.jpg` | 리포트 헤더 밴드 배경 (흑석 원석 + 옳은영어 등대, 밤바다) | 900×386 |
| `icon_timeline.jpg` | 01 차시별 제출 | 128×128 |
| `icon_calendar.jpg` | 02 제출 달력과 주차별 진도 | 128×128 |
| `icon_comment.jpg` | 03 담임 코멘트 | 128×128 |
| `teacher.jpg` | 담임강사 김성진T 프로필 | 220×440 |
| `logo_orun.png` | 옳은영어 등대 로고 (투명 배경) | 72×72 |

흑석고 로고는 여기 두지 않는다 — 앱이 `schools.logo_url` 에서 가져온다.

아이콘은 흑석고 로고(인디고 원석)에서 색과 결을 따왔다. 연한 인디고 바탕
`#F1F1F7` 에 인디고 `#3A3C74` 선, 각 아이콘에 크리스털 패싯이 한 조각씩 있다.
바꿀 때도 이 규칙을 지킨다 — 바탕이 따뜻한 아이보리로 돌아가면 헤더와 따로 논다.

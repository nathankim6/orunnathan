# 선생님 기억 (teacher-memory)

별도 웹앱(ORUN ORACLE) 없이, **이 저장소 파일 + Claude 와의 대화만으로** 같은 일을 한다 —
선생님별로 기출문제·시험범위·프린트를 넣으면 문항 단위로 데이터화하고, 출제 성향을
프로파일로 학습(누적)하고, 다음 시험을 예측해 적중 동형모의고사를 만든다.

이 폴더는 배포되지 않는다. 웹에서 열리는 주소가 없고, `pages.yml` 이 나열하지도 않는다.
순수하게 대화 안에서 Claude 가 읽고 쓰는 "기억 저장소" 다.

**절차는 `.claude/skills/teacher-memory/SKILL.md` 에 있다.** 사용자는 그냥 대화로
"OO 선생님 2025-2 중간고사 기출 여기 있어요" 라고 말하면 되고, Claude 가 이 스킬을
따라 알아서 이 폴더에 저장·분석·누적한다.

## 원칙

1. **선생님 한 분 = 폴더 하나.** 그 폴더가 그 선생님에 대해 Claude 가 아는 전부다.
   다른 선생님 폴더와 섞이지 않는다.
2. **덮어쓰지 않는다.** `profile.md` 는 새 버전을 계속 밑에 쌓는다(v1 → v2 → v3 …). 예전
   판을 지우면 "성향이 어떻게 바뀌어왔는가"(드리프트)를 다시 볼 수 없게 된다.
3. **원문은 그대로 보존한다.** `sources/` 밑 파일은 사용자가 준 원문을 요약·의역 없이
   그대로 담는다. 데이터화(문항 단위 JSON)는 별도 파일(`questions/`)에 만든다.
4. **숫자는 세어서 낸다.** 프로파일의 비율·평균 같은 숫자는 `scripts/count_stats.py` 로
   계산한 값을 쓴다. 눈대중으로 "대략 30%" 라고 쓰지 않는다.
5. **커밋한다.** 이 폴더는 git 으로 버전 관리되는 진짜 기억이다. 선생님 자료를 넣거나
   프로파일을 갱신했으면 커밋해서 남긴다(푸시 여부는 사용자 지시를 따른다).

## 구조

```
teacher-memory/
  schools/
    <학교-슬러그>/                       예: heukseok-go
      teachers/
        <선생님-슬러그>/                 예: yoon-eunyoung
          info.md                        이름·과목·학년·메모
          sources/
            exams/<연도-학기-시험명>.md   기출 원문 (원문 그대로)
            scope/<연도-학기>.md          시험범위 원문
            handouts/<이름>.md            선생님 프린트 원문
          questions/<연도-학기-시험명>.json  그 시험 문항의 데이터화 (스키마는 SKILL.md)
          profile.md                     출제 성향 프로파일 — 버전 이력 전부 보존
          predictions/<날짜>-v<n>.md     다음 시험 예측 청사진
          mock-exams/<날짜>-v<n>.md      생성된 적중 동형모의고사
  scripts/
    count_stats.py                       questions/*.json 을 세어 분포·평균을 뽑는 스크립트
```

## 지금 있는 선생님

흑석고 영어 두 분이 시드로 들어있다 (ORUN ORACLE 과 동일한 시드) —

- `schools/heukseok-go/teachers/yoon-eunyoung` — 윤은영, 1학년 영어A
- `schools/heukseok-go/teachers/jeon-jeongyi` — 전정이, 1학년 영어B

아직 자료가 없는 빈 폴더다. 기출·범위·프린트를 대화로 주면 그때부터 쌓인다.

## ORUN ORACLE 과의 관계

같은 개념(문항 데이터화 → 지문 매칭 → 성향 프로파일 → 예측 → 적중 모의고사)을 쓰지만
**서로 다른 저장소이고 동기화되지 않는다.** ORUN ORACLE 은 브라우저(IndexedDB + Supabase)
에 웹앱으로 돌고, 이 폴더는 이 저장소 파일 + Claude 대화로 돈다. 한쪽에 넣은 자료가
다른 쪽에 자동으로 나타나지 않는다 — 이 저장소를 쓰기로 했다면 계속 이 저장소에만 넣는다.

## 담당 추정 (범위표에 적혀 오지 않았다)

1학기 분담을 그대로 따랐다 — **윤은영 = 올림포스(부교재) + 교과서 2과**, **전정이 = 교과서 1과 + 뉴스(외부지문)**.
확인되면 이 줄과 두 예측 파일을 고친다.

## 1학기 직보 원문과 시험지를 대조해 찾은 "원문을 바꾸는 방식"

| | 윤은영 | 전정이 |
|---|---|---|
| 지문 | 원문 그대로 | 문장마다 다시 쓴다(동의어 · 능동↔수동 · 구조 바꾸기) |
| 이어 붙이기 | 안 한다(한 지문 한 문항) | 교과서도 뉴스도 두세 토막을 잇는다 |
| 빈칸 | 원문 구를 비우고, **정답은 그 구를 바꿔 쓴 말**(developing → building) · 오답 넷은 반대 방향 | (1학기 0문항) |
| 어법 | 원문 한두 곳만 비튼다 | 다시 쓴 문장 안에 심는다 · (a)~(e) 문장 단위 |
| 어휘 | 반의어 하나 · 교과서는 워크시트 영영풀이 한 자리 바꿔치기 | 반의어 하나 · 영영풀이 뒤집기 |
| 삽입·순서·무관 | 원문 문장을 빼내거나 원문을 세 토막 · 무관은 자작 한 문장 | 새 문장을 써서 담화표지(Rather · As a result · Likewise)를 심는다 |
| 지칭 | — | 같은 대상을 다른 이름으로 바꿔 부른다 |

두 모의고사는 이 방식대로 만들었다 — 윤은영 문항의 지문은 원문과 한 글자씩 대조해 **의도한 변형 말고는 다른 곳이 없음**을 확인했다.

## 시험이 끝나면

실제 시험지를 받으면 스킬 §6 대로 두 예측 파일·두 모의고사와 맞춰 보고(유형·지문·변형 방식이 맞았나),
그 결과로 각 선생님 `profile.md` 를 새 판(v4)으로 올린다. 이번 예측이 틀린 곳이 곧 페르소나를 고칠 근거다.

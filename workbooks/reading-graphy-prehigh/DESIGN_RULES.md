## 2. 인물 — `person(o)` (= `figure.js` `figure`)

```js
person({ x, y, s, c, pose, arms, legs, hair, hairc, face, brow, look, skin, top, sleeve,
         glasses, held, capc, legc, shoec, flip, tilt })
```

| 키 | 값 | 비고 |
|---|---|---|
| `x,y` | 발밑 중앙 | 패널 안 인물은 **y = 패널 바닥선(y+h−8)** 에 세운다 (2패널 y 200 · 3패널 y 200) |
| `s` | 배너 **1.0**(2패널) · **.85**(3패널) | validate.js 가 .6 미만을 거부한다. 비네트에는 인물을 넣지 않는다 |
| `c` | 상의색 = 레슨 accent(또는 deep 한 명) | 바지는 `legc`(LEGC 4색), 신발은 `shoec`(기본 갈색 SHOE) — 검정 금지 |
| `pose` | down hold carry point think up wave cheer open shrug write | `arms:{L,R}` 로 양팔 독립 지정(이름 또는 `{pts,hand,front,wrap,ang}`). **hold 는 wrap 손**: 손바닥은 소품 뒤, 손등+손가락 3선+엄지가 소품 앞면 가장자리에 걸친다 |
| `head` | 도(°) | 목 기준 머리 기울기. 생각하는 인물 5° — 두 인물이 같은 자세로 좌우 대칭이 되지 않게 |
| `legs` | stand step walk sit | 생략 시 point/open/shrug → step, 나머지 stand. **stand 는 contrapposto(왼다리 벌림 + 왼발 뒤꿈치 8° 들림 + 상체 2°, `tilt`)** |
| `hair` | short bob long bun pony twin curly wavy buzz cap | `hairc` HAIRC 6색. cap 은 `capc` |
| `face` | smile glad laugh flat worry oh grin **meh** | `brow` soft **low** up down one none. `look` 으로 시선 ±4. '밋밋하다·글쎄' 는 `face:"meh", brow:"low"` (flat + 일자 입은 화난 얼굴로 읽힌다) |
| `skin` | light tan brown | |
| `top` | **tee**(=crew, 가슴 주머니) **shirt**(칼라·단추·주머니) **hoodie**(후드·끈·캥거루 주머니) **sweater**(V넥·리브) **apron** | 한 배너 안 인물끼리 top 을 다르게 |
| `sleeve` | long(손목 소매 밴드) · short(팔뚝 노출) | |
| `held` | `prop.xxx(0,-78,s,c)` 문자열 | 직접 쓰지 말고 `holding(o, prop.book, 1.15)` 를 쓴다 — 소품 반폭(`prop.xxx.hw`)에 맞춰 손목을 잡는다. 한 손: `holding(o, prop.book, 1.15, {one:"L", R:"think"})` — 소품이 ox−3(=−9) 로 당겨지고 **손목은 소품 아랫변 바로 밑 (−9, −78+hh·s+1)**(`prop.xxx.hh` = 소품 아래 반높이), 손은 **`cup`**(손바닥은 소품 뒤·아랫변 밑, 손가락 끝 3 + 엄지만 아랫변 위로 2–3px, ang −90), 팔꿈치는 옆구리 높이 (−(hw+6), −80) 로 전완이 소품 밑으로 들어간다 → '아래에서 받쳐 든' 모양. 손을 펼친 면 한가운데 얹으면 '책 위에 손을 붙인' 것으로 읽힌다 |
| `glasses` | 0/1 | |

원칙
- **손은 항상 노출** (fist / open / point / grip 4형이 포즈에 따라 자동). 소품은 팔 위·손 아래 레이어에 끼워지므로 책이 손을 가리지 않는다.
- **손목이 턱(−115)보다 위인 팔(think 등)은 머리 그룹 뒤(맨 위 레이어)에 그려진다** — bob/long 의 옆 갈래 머리에 팔뚝이 묻히지 않는다. think 팔꿈치는 (40,−82) 로 바깥에 있어 팔뚝이 머리카락 옆으로 보인다.
- 잉크선은 따뜻한 갈색 `INK #3A2E27`, 굵기 LW 1.8(보이는 선 0.9 → s=1 에서 0.25mm). 얼굴·팔·소품 모두 같은 선.
- 명암은 `shade(c)` 2톤 셀 하나. 그라디언트·투명도 그늘 금지. 얼굴은 눈 하이라이트 + 볼터치 + 머리 하이라이트 1스트로크가 기본 포함.
- 소품·풍선 위치는 `anchors(o)` 로 계산한다: `mouth wristL wristR headTop hands chin hip shoulderL/R eye`. 좌표를 손으로 찍지 않는다.
  - **팔 굵기 2단**: 상완 12 · 전완 11(`ARM_W`, `tube2` — 잉크 외곽 두 마디 먼저, 채움 나중). 두 손 hold 팔꿈치는 **(±(hw+14), −94)** 로 바깥·위에 열어 상완 ≥18px · 팔꿈치 각 ≈78° — 팔꿈치를 어깨 옆에 붙이면 두 마디가 겹쳐 어깨가 혹처럼 부푼다.
  - 풍선: `bubble({…, to:{x:m.x+20, y:m.y}})` — 풍선을 **입 높이(y 82–134)** 에 두면 꼬리가 옆변에서 얼굴 가장자리(4px 앞)까지 나간다. `to` 가 풍선 아래면 아래변 꼬리(길이 10–30, to 4px 앞까지). 꼬리 끝이 40px 넘게 허공에 뜨면 풍선 위치가 잘못된 것이다.
  - 전구: `up` 포즈의 `wristR` 옆 (`hR.x+20, hR.y−6`).
- 인물 시트 확인: `node figsheet.js` → `pv/figures.html` 을 chrome 헤드리스로 스크린샷.

## 5. 비네트 (240×150 → 45mm) · 아이콘 · 픽토그램

- **비네트는 인물 없이 소품 도해 1개**: 구체·프레임·체크리스트·물레·책 등 + `tag`(lvl "v") 1–2개 + `text(..,"vs",MID)` 라벨 ≤2. 축소 시 손발이 뭉치는 인물, lvl 3(5pt) 라벨은 금지. SVG 안에 제목을 넣지 않는다(캡션이 따로 찍힌다).
- 옛말→새말 같은 대응은 **흰 외곽선 칩 → 화살 → deep 채움 칩** 으로 (Unit 1 canali → canals).
- 구체(행성)는 오른쪽 그림자 반구(deep .18) 하나로 입체를 준다(상단 흰 타원 하이라이트 금지 — 스티커처럼 보인다). 대비는 **왼쪽 굽은 호 vs 오른쪽 곧은 직선** 처럼 형태 + 선 굵기로 말한다: 자연 = 흰 SW.hair 곡선(.85) · 인공 = 흰 SW.line 직선(.95).
- 캡션(`VIGCAP[no]`)은 **50mm 상자 한 줄**(한도 118pt — 넘으면 말줄임으로 조용히 잘리고 `validate.js` 가 잡는다). KB 제목과 다른 문장 — 도해가 가리키는 사실 하나(연도·이름·대응). 도해 안 태그(canali/canals)를 캡션이 글자 그대로 되풀이하지 않는다(Unit 1: '스키아파렐리의 화성 지도 · 1877').
- 대비는 **같은 소품 둘을 나란히**(Unit 1: 굽은 물길 구체 vs 곧은 직선 구체, 사이 화살표) 로 보여 준다 — 오른쪽 낱말 태그가 설명을 대신하게 하지 않는다.
- 레슨 아이콘 64×64: 선화 stroke 3 round, 라이브 48×48, 면 채움은 accent 30% 한 곳.
- 플로차트 픽토그램(`pics.js`) 48×48: 선 2.6 round, 채움은 틴트 원/면만, 순색 면적 ≤30%. 'A possible answer' 는 `swap`(⇄). **상단 픽토그램 띠는 없다** — 픽토그램은 `table.flow` STAGE 열 안, 스테이지 이름 앞 6mm 틴트 원에 인라인(같은 이름을 두 번 찍지 않는다). p4 하단 MEMO 블록도 없다. **플로차트는 타임라인**: STAGE 열(`td.step`)은 행 헤어라인을 끊고(`border-bottom:0`, 헤어라인은 `td.body` 에만) `td.step::after` 가 픽토그램 원 아래에서 다음 원 위까지 **1.25pt accent 70%** 연결선 + `::before` 삼각 화살촉(2.2mm) 을 붙인다(마지막 행 제외) — 흐름선이 구분선보다 진해야 5행 표가 아니라 흐름으로 읽힌다. 행 패딩 `table.flow td` 3.2mm · `table.para td` 8.2mm · `.sect.para` 위 4.5mm.

## 6. 금지 사항

1. 검정 신발·검정 슬래브 발, 손 없는 소매, 책이 손을 가리는 구성.
2. 배너 인물 s < .85(3패널) / < 1(2패널) — 패널이 비어 보인다. 비네트에 인물.
3. 패널 없는 열린 구도(다른 배너와 규격이 어긋남). 패널 안에 라벨 칩을 두 개 이상 겹쳐 넣기(리더선으로 밖에 뺀다).
4. 회색 hex 직접 쓰기(MID/LIGHT 만), 노랑 2곳 이상, 틴트 노트 2개 이상, 그라디언트·드롭섀도.
5. 5pt 미만 글자(비네트는 15 units 미만), 캡션 줄과 겹치는 라벨.
6. `anchors()` 를 거치지 않은 풍선 꼬리·소품 좌표.
7. css.js 의 토큰(:root)·과제 헤더·범례색 변경. 유닛 파일에서 스타일을 인라인으로 덮어쓰기.

## 7. 작업 절차

```
node build.js --unit=N && ./render.sh N
python3 snap.py uNN.pdf 1,6,11,16,21 pv 150      # 배너 5장 (fig 크롭 대신 전면을 보고 아래쪽 배너를 확인)
python3 snap.py uNN_t.pdf 3 pv 130               # 교사용 READ RIGHT 15문장이 푸터 위에서 끝나는지
node validate.js N · python3 clip.py uNN · python3 clip.py uNN_t · python3 wrap.py uNN.pdf · python3 legend.py uNN.pdf
```
- `clip.py` 는 잘림(누락 토큰)과 함께 **푸터 침범**(본문 스팬이 y 793pt 아래로 내려옴 = 아래 여백 18mm 침범)도 잡는다. 면이 넘치면 글자 크기가 아니라 여백·행 간격에서 덜어 낸다.
- **하단 한계는 하나**: `.page` 아래 패딩 22mm(본문 한계 275mm → 푸터 위 ≈11mm). p2(`.sect.grow` 의 구문 훈련 쓰기줄 3개)·p3(해석 줄 15개)은 남는 높이를 flex 로 나눠 가져 한계에서 끝나고(넘치는 면은 `flex-shrink:0` 이라 그대로), p4 는 행 패딩으로, p1 은 `.gap` 8mm 로 맞춘다 — 레슨 5면의 마지막 잉크→푸터가 11±2mm(p5 ≈13.6). 측정: 140dpi 로 마지막 잉크 행과 푸터 첫 행 사이.
- `legend.py` 는 Check Up 범례가 [지시 1줄]+[범례 1줄] 두 줄이고 본문 폭 안인지 검사한다.

## 8. 면 넘침 자동 보정 (build.js 가드 스크립트) — css 작업자용 메모

- build.js 가 `<head>` 에 넣는 가드 스크립트가 인쇄 직전 면마다 본문 하단을 재서 **279mm 를 넘을 때만** 단계적으로 클래스를 붙인다: 레슨 p1 은 `dense → snug → denser`(지문 행간 1.7 → 간격 축소 → 1.6), 정답 면은 `tight`. 정적 규칙(지문 1030자 초과 → `dense`)은 그대로 두고, 가드는 그 아래에서만 작동한다.
- `clip.py` 는 푸터 글줄이 아닌 스팬이 y 793pt 아래로 내려오면 전부 '푸터 침범' 으로 잡는다(캡션이 통째로 푸터 영역에 들어간 경우 포함). `wrap.py` · `legend.py` 는 본문 열(LEFT−6 … RIGHT+6) 안만 재므로 좌우 인덱스 탭이 오탐을 내지 않는다.
- 교사용 패러프레이즈 정답(`table.para .ans`)은 `white-space:nowrap` — 하이픈(self-check)에서 줄이 갈리지 않는다.

# 수능 유형 문제 세트 — 가짜 뉴스 교과서 + 모평·수능 기출

엑셀로 받은 지문 25편에 대해, 화면에서 선택한 수능 9개 유형으로 **218문항**을 만든 자료입니다.

## 결과물

`옳은영어_수능유형_문제세트.docx` (A4, 옳은영어 서식)

- **PART 1 문제편** — 지문별로 유형 순서대로 배치. 지문 하나가 새 쪽에서 시작합니다.
- **PART 2 정답 및 해설** — 지문 해석, 문항별 정답·해설, 영어 보기의 한글 해석.

## 출제 유형

| 수능 번호 | 유형 | 문항 수 |
|---|---|---|
| [21] | 함축 의미 | 25 |
| [22] | 요지 | 25 |
| [23] | 주제 | 25 |
| [24] | 제목 | 25 |
| [25-27] | 내용 불일치 | 25 |
| [32-34] | 빈칸 추론 | 25 |
| [36-37] | 글의 순서 | 25 |
| [38-39] | 문장 삽입 | 18 |
| [40] | 요약문 완성 | 25 |

문장 삽입은 ①~⑤ 다섯 자리를 표시하려면 지문이 6문장 이상이어야 합니다. 5문장 이하인 7개
지문(25년9월23번, 22년9월 22·23·24·29·34·35번)은 이 유형을 넣지 않았고, 해당 지문 끝에 그
사실을 적어 두었습니다.

## 다시 만들거나 고치려면

```sh
pip install python-docx openpyxl
python3 build/check.py     # 출제 데이터 전수 점검
python3 build/render.py    # docx 다시 만들기
```

| 파일 | 하는 일 |
|---|---|
| `build/passages.json` | 엑셀에서 뽑은 지문 25편(영어·해석). 교과서 지문의 제목과 22년9월40번 끝의 요약문은 문제에 답이 새지 않도록 따로 분리해 두었습니다. |
| `build/split.py` | 지문을 문장 단위로 자름. 순서·문장삽입 문항이 이 번호를 씁니다. |
| `build/items.py` | **출제 데이터.** 문항을 고치려면 여기만 손대면 됩니다. |
| `build/balance.py` | 정답 번호를 ①~⑤에 고르게 재배치. 해설 속 번호와 보기 해석 순서, 순서 문항의 (A)(B)(C) 라벨도 같이 맞춥니다. |
| `build/check.py` | 밑줄·빈칸 구문이 원문에 있는지, 순서 블록과 문장삽입이 원문을 그대로 복원하는지 등을 점검. |
| `build/render.py` | 워드 문서 조판. |
| `build/dump.py` | 완성된 docx를 텍스트로 뽑아 교정용으로 봅니다. |

`items.py`에서 보기를 고칠 때는 정답을 몇 번에 두든 상관없습니다. `balance.py`가 문서를 만들 때
자리를 다시 나눠 주기 때문입니다. 다만 해설에서 보기를 가리킬 때는 반드시 ①~⑤ 기호를 쓰세요.
그래야 번호가 바뀔 때 해설도 함께 따라갑니다.
